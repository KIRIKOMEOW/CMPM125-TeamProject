## 需要修改

### 1. Guard Bot 发现不了玩家时，这一波会卡住结束不了

Guard Bot 刷出来离玩家至少 8 单位，探测范围是 12，而且要有视线。它只在出生点附近 ±2 单位巡逻，所以玩家躲在箱子后面或者站在场地另一头时，它可能永远发现不了玩家。剩余敌人数就一直不归零，这一波结束不了。

请加一个"听到动静去查看"的决策（正好也给"AI 决策"那项评分加分）：

- Guard Bot 处于 Patrol 状态超过 `investigateAfter` 秒（默认 5 秒）还没看到玩家时，把 `lastSeenPosition` 设成玩家**当前位置**，进入 Search 状态走过去查看。
- Search 结束（3 秒）后如果还是没看到，回到 Patrol，并以当前位置作为新的巡逻中心（重新生成 ±patrolRadius 的两个点），这样它会一步步向玩家靠近。
- 头顶状态标签会显示 Search，录视频时能看出它在"找人"。

### 2. 油桶的连锁爆炸要一下就炸

现在一个油桶爆炸只算对另一个油桶的"一次命中"，它要被炸两次才会爆。连锁爆炸是视频里最好看的物理演示，希望一炸就连环炸：

- `ExplosiveBarrel.TakeDamage` 里，如果 `info.source` 上有 `ExplosiveBarrel` 组件（即伤害来自另一个油桶的爆炸），直接 `Explode()`。
- 连锁引爆要么延迟一帧，要么用一个很短的延迟（0.08 秒，用协程加 `WaitForSeconds`），这样连锁有"砰、砰、砰"的节奏，而不是同一帧全炸。注意延迟期间如果进入暂停、商店或 RunReset，要取消。
